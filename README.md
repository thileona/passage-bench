# HEK293 Passage Bench

Phone app (PWA) for suspension HEK293 shake-flask passaging: split, top-up, dilution, growth and scale-up calculators, protocol, bench checklist and key concepts.

Hosted with GitHub Pages. Install from the phone browser: Android Chrome → menu → Install app; iPhone Safari → Share → Add to Home Screen.

To update: replace `index.html` (and other changed files) in the repo. The app picks up the new version the next time it opens online.
